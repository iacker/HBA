The Bare Skeleton

What a stock agent lacks

Hermes out of the box is capable but exposed: it forgets, it trusts, it overpays, and it lives in one place. HBA is the armor forged over those four gaps — nothing here forks the core.

Forgets

No memory between sessions. Every conversation starts from nothing.

→ A four-tier memory

Working, identity, episodic, semantic — one felt mind, the right store per question.

Trusts blindly

API keys in a plaintext .env; full access, no containment.

→ Sealed by hardware

Keys in the Secure Enclave, profiles that can lock themselves, a read-only auditor.

Overpays

The whole tool catalog re-billed on every single turn.

→ A token scalpel

Only the relevant tools surfaced per turn — a large arsenal made affordable.

Single-homed

Lives on one machine. If it is down, it is gone.

→ One will, three bodies

The same agent projected across Azure, a k3s cluster, and this Mac.

Read path: what is already in context (working + identity) costs nothing to consult; episodic and semantic memory are reached only when that is insufficient. Write path: sessions are consolidated into the episodic graph, durable lessons are promoted up into identity memory so they load free next time, and vault documents are indexed for semantic recall. The agent behaves as if it has one memory — each question served by the store that answers it cheapest and truest.

brain-rag-serversemantic memoryself-builtpublic

Local hybrid-RAG MCP server over a markdown / Obsidian vault. fastembed MiniLM embeddings and a BM25 full-text index in embedded LanceDB, merged with reciprocal rank fusion. No cloud, no GPU, no database server, no daemon.

Role Gives the agent everything you have ever written, retrievable by meaning.

agentmemoryepisodic memorythird-party · integrated

Consolidates session observations into a tiered store and a knowledge graph — past decisions, lessons, and how facts relate. Queried on demand when the current context is not enough.

Role The agent's memory of its own past work.

hermes-lcmworking memoryHermes plugin

Context compaction: folds a long running conversation into a hierarchical summary DAG plus a protected recent tail, so a session never overflows the window while keeping precise recovery of anything summarised.

mem0 · pgvectoridentity memorythird-party · integrated

Stable facts and preferences persisted in Postgres / pgvector, injected every turn and shared across every body of the fleet, surviving restarts.

The Sword-Arm — Reach

Tools it fights with

Broad capability, loaded on demand, kept cheap, and bounded. The strategy hangs on one keystone: a big arsenal is only wise if it does not tax every turn.

mcp-scalpelthe keystoneself-builtpublic

When an MCP client connects to a gateway of many tools, the entire catalog — names, descriptions, JSON schemas — is injected into every LLM call. Measured on a live Docker MCP Gateway: 49 tools ≈ 18,700 input tokens per turn, re-sent forever.

Scalpel sits as a stdio proxy between client and gateway, intercepts tools/list, and returns only the ~15 tools relevant to the session — 35–52% fewer catalog tokens per turn.

It never sees the prompt, only JSON-RPC frames, so it routes on session context. A meta-tool scalpel_search_tools(query) pulls any hidden tool's full schema on demand (progressive disclosure); low-signal queries fall back to the full catalog and tools/call is always relayed, so nothing is ever un-callable. Pure-numpy TF-IDF: milliseconds, no cloud.

Why it is the keystone It is what makes "give the agent a lot of tools" affordable instead of a permanent per-turn tax. Every other reach tool below is cheap to keep because scalpel only surfaces it when relevant.

ab-livethe real browserself-builtprivate

Drives your actual browser — cookies, sessions, extensions — live inside the Hermes pane, not a headless throwaway. The agent acts as you on authenticated sites where no API exists, and you can watch it move.

Role Real-world action with your real identity.

The Seals — Defense

Power without blast radius

An agent with a shell is a blade pointed at your own machine, and prompt injection means a bad instruction will eventually slip through. The seals do not stop the agent working — they make sure a compromised one has little worth stealing and little it can undo.

heucatthe key never leaves the hardwareself-builtpublic

Hardware Enclave Credential Authentication Tool. A stock agent's keys sit in a plaintext .env, one file-read from exfiltration. heucat serves them from the macOS Keychain instead, encrypted with a key that never leaves the Secure Enclave, gated behind Touch ID. It plugs in as a Hermes secret source: the agent asks for a key by name, the enclave decides whether to release it.

Seals the power "The agent holds API keys." Even with full shell access, there is no plaintext key file to read.

hermes-chthoniosthe agent can lock itself outself-builtpublic

A secret manager decides where credentials live; chthonios decides whether a profile may hold them at all. It encrypts a profile's .env into ciphertext. A sealed profile's gateway starts, finds no key, and cannot call any model until a human unlocks it.

Sealing needs only a public recipient — an unattended agent can seal itself. Unsealing needs the physical YubiKey in a hand: touch and PIN.

So an autonomous agent can revoke its own access to its credentials without keeping the means to undo it. A UI passcode only stops a glance at your screen and falls to a shell, because the plaintext is still there. chthonios removes the plaintext — there is nothing to bypass.

Seals the power "The profile holds state at rest."

hermes-argusan honest measure of exposureself-builtpublic

You cannot bound a blast radius you cannot see. argus reads the Hermes config and cross-checks it against the ports actually listening on the machine, then grades real exposure: is the shell sandboxed or on the host? Are risky actions gated behind approval? Is the dashboard published without a password? Are A2A / MCP ports reachable without auth? Are secrets kept out of the environment and logs? Unlike scanners that scream CRITICAL at a healthy setup, it scores honestly — and never reads or writes a secret, never changes a thing.

Measures How well the other two seals are actually holding.
